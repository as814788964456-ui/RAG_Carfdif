# LIFE-Core 核心保單系統操作手冊

LIFE-Core 是本公司的保單行政核心系統，記錄所有有效及失效保單的契約內容、繳費紀錄、保全變更及理賠給付紀錄。網址：https://lifecore.aurora.example（僅限公司內部網路或 VPN 連線）。

## 一、權限申請

1. LIFE-Core 使用**獨立帳號密碼**（非 AD 帳號），密碼有效期 60 天
2. 由直屬主管於 eFlow 提出表單 **IT-05「應用系統權限申請單」**，勾選所需角色
3. 簽核：主管 → 系統業務窗口（保險作業處）→ 資訊安全科
4. 開通需 **3 個工作天**；新人須先完成 e-Learning「個人資料保護」課程，系統才會開通
5. 權限依「最小權限原則」設定，常見角色：

| 角色代碼 | 名稱 | 可執行功能 |
|---|---|---|
| R01 | 保單查詢 | 查詢保單基本資料、繳費紀錄（客戶身分證號部分遮蔽） |
| R02 | 新契約登打 | 要保書資料登錄 |
| R05 | 保全作業 | 契約變更登錄與覆核 |
| R07 | 理賠查詢 | 查詢理賠紀錄（給付作業另於 ClaimPro 系統） |
| R09 | 完整個資檢視 | 顯示完整身分證號與聯絡資料，需處級主管核准，每次檢視留有紀錄 |

## 二、保單查詢操作

1. 登入後點選左側選單「保單查詢」
2. 可用以下條件查詢（擇一）：
   - 保單號碼（格式：2 碼英文商品別＋10 碼數字，例如 `WL0012345678`）
   - 要保人或被保險人身分證字號
   - 要保人姓名＋生日
3. 查詢結果頁籤：
   - 「契約內容」：商品、保額、生效日、繳別、繳費年期
   - 「繳費紀錄」：應繳日、實繳日、繳費方式、是否進入寬限期
   - 「保全紀錄」：歷次契約變更
   - 「理賠紀錄」：理賠申請日、給付金額
   - 「保單價值」：解約金、保單借款可借金額、借款餘額

**注意**：查詢客戶資料必須有業務需要，系統保留所有查詢紀錄，稽核室每月抽查。基於好奇查詢親友或名人保單屬違規，依員工手冊懲處。

## 三、列印與匯出

- 保單資料列印會自動加上浮水印（列印人員編號與時間）
- R01 角色**不可**匯出 Excel；需批次資料請透過 iService 提出「資料調閱申請」，經處級主管核准後由資訊處提供

## 四、常見錯誤代碼

| 錯誤代碼 | 訊息 | 原因與處理 |
|---|---|---|
| E-101 | 帳號或密碼錯誤 | 連續錯 3 次鎖定，需透過 iService 提出「應用系統密碼重設」 |
| E-102 | 密碼已過期 | 登入畫面點「變更密碼」，輸入舊密碼後設定新密碼 |
| E-305 | 查無資料 | 保單號碼格式錯誤或保單已移轉至歷史庫；10 年以上失效保單請改用「歷史保單查詢」功能 |
| E-401 | 權限不足 | 您的角色無此功能權限，請主管提出 IT-05 申請 |
| E-512 | 系統逾時 | 查詢條件過寬（例如只輸入姓名），請加上生日或改用保單號碼；若單一保單查詢也逾時，請開 iService 工單 |
| E-900 | 系統維護中 | 每月最後一個週六 22:00 至週日 06:00 為例行維護時間 |

## 五、系統服務時間

- 線上作業：每日 07:00–23:00
- 每日 23:00–07:00 為批次作業時間（保費入帳、保單週年處理），僅開放查詢
- 例行維護：每月最後一個週六 22:00 至週日 06:00，系統完全關閉
