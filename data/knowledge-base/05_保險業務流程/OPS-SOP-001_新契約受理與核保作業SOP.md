# 新契約受理與核保作業 SOP

## 一、流程總覽

```
業務員收件 → 新契約部受理與文件檢核 → 核保（自動／人工）→ 照會（必要時）→ 核保決定 → 收取首期保費 → 保單製發 → 契約撤銷期
```

## 二、受理與文件檢核（新契約部）

1. 業務員應**親晤**要保人及被保險人，並由本人**親簽**要保書
2. 送件後新契約部於 **1 個工作天**內完成文件檢核，並於 LIFE-Core 登打（R02 角色）
3. 必備文件：
   - 要保書（含告知事項，由被保險人據實填寫）
   - 要保人、被保險人身分證明文件影本
   - 客戶風險屬性與需求評估（KYC／適合度分析）；投資型保險另需投資風險屬性問卷
   - 首期保費繳費授權書或繳費證明
   - 業務員報告書
4. 文件不齊或填寫錯誤者，以「補件通知」送業務員，**補件期限 7 個日曆天**

## 三、核保

### 3.1 自動核保

2025 年起導入核保規則引擎（見 PRJ-002），符合下列條件之案件由系統自動核保：
- 被保險人年齡 0–55 歲
- 告知事項全部勾選「否」
- 未達體檢門檻
- 同一被保險人在本公司累計身故保額 **新台幣 1,000 萬元以下**

自動核保案件於受理後 **1 個工作天**內完成。目前約 **62%** 新契約案件為自動核保。

### 3.2 人工核保

不符合自動核保條件者轉人工核保，由核保人員於 UW Workbench 審查。

- 作業時效：文件齊全後 **5 個工作天**
- 需體檢者：收到體檢報告後 **5 個工作天**

### 3.3 體檢門檻（依被保險人年齡與累計身故保額）

| 被保險人年齡 | 免體檢最高累計保額（新台幣） |
|---|---|
| 0–40 歲 | 500 萬元 |
| 41–50 歲 | 300 萬元 |
| 51–60 歲 | 200 萬元 |
| 61 歲以上 | 100 萬元 |

超過門檻者，由核保部安排至本公司特約體檢醫院體檢，**體檢費用由公司負擔**。

## 四、照會

核保人員需要客戶補充資料時（例如病歷、財務證明、職業說明），發出「照會單」：
- 照會回覆期限為 **15 個日曆天**，可申請延長 1 次 15 天
- 逾期未回覆者以**撤件**處理，已繳保費無息退還
- 業務員可於 LIFE-Core「照會查詢」或撥核保部分機 4100 查詢照會狀態

## 五、核保決定

| 決定 | 說明 |
|---|---|
| 標準體承保 | 依標準費率承保 |
| 加費承保（次標準體） | 風險較高，加收保費後承保 |
| 批註除外 | 特定疾病或部位不在保障範圍內，需要保人書面同意 |
| 延期 | 暫不承保，待一定期間後再評估（例如手術後 6 個月） |
| 拒保 | 風險過高不予承保，以書面通知，已繳保費無息退還 |

加費承保及批註除外，須取得要保人書面同意後始得承保；要保人不同意者視同撤件。

## 六、保單製發

- 承保且首期保費入帳後 **2 個工作天**內製發保單
- 客戶可選擇**電子保單**（寄送至要保人留存 Email，以身分證字號為開啟密碼）或紙本保單（掛號郵寄）
- 保單送達後，業務員應取得「保單簽收回條」並於 **10 天**內送回新契約部

## 七、契約撤銷權

依人身保險示範條款，要保人於保單送達翌日起算 **10 日內**，得以書面或其他約定方式檢同保單向本公司撤銷契約，本公司應無息退還已繳保費。撤銷申請由保全服務部受理（OPS-SOP-002）。

## 八、注意事項

- 員工不得經手本人或二親等以內親屬之核保案件（HR-001 第五章）
- 業務員不得代客戶填寫告知事項；發現代填情形應通報通路業務處
