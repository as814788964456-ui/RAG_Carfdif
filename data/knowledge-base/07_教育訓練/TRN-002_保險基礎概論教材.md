# 保險基礎概論（新人訓教材）

## 單元一：保險是什麼？

### 1.1 風險與保險

人生中有許多無法預測的風險：生病、意外、早逝、長壽（退休金不夠用）。保險的原理是**風險分散**：許多人各繳一筆相對小的保費，集合成一筆基金，由其中少數真正發生事故的人領取保險金。

### 1.2 大數法則

單一個人何時發生事故無法預測，但當被保險的人數夠多時，整體的事故發生率會趨於穩定。保險公司依據生命表與經驗統計，就能合理計算保費。這也是為什麼**據實告知**很重要：若高風險的人隱瞞病史投保，會破壞費率公平，最後由所有保戶共同承擔。

## 單元二：一張保單裡有誰？

### 2.1 三個關係人

用一個案例理解：

> 王大明（40 歲）為自己投保終身壽險，保額 300 萬元，身故受益人是太太林小芳；同時幫 8 歲的女兒王小安投保醫療險。

| 保單 | 要保人 | 被保險人 | 身故受益人 |
|---|---|---|---|
| 終身壽險 | 王大明 | 王大明 | 林小芳 |
| 兒童醫療險 | 王大明 | 王小安 | （醫療保險金受益人通常為被保險人本人） |

- **要保人**繳錢，也掌握保單權利（解約、借款、變更受益人）
- **被保險人**是保障對象
- **受益人**領保險金

### 2.2 小測驗

1. 王大明想把壽險受益人改成女兒，需要誰同意？
   - 答：由要保人王大明提出，且因身故受益人變更須經被保險人同意，而被保險人就是王大明本人，因此王大明本人簽名即可（OPS-SOP-002）
2. 王小安的醫療險，誰有權利申請解約？
   - 答：要保人王大明

## 單元三：保單的錢從哪裡來、到哪裡去？

### 3.1 保費的組成

保費大致分為：
- **危險保費**：用來支付當年度可能發生的理賠
- **儲蓄保費**：累積成保單價值準備金（終身型、儲蓄型商品才有較多）
- **附加費用**：公司營運與通路佣金

### 3.2 為什麼前幾年解約會「虧錢」？

保單前幾年的附加費用比例較高，且保險公司已經提供了保障，因此投保初期的**解約金通常低於已繳保費**。這是客戶最常抱怨的地方之一，第一線人員應在客戶詢問解約時，先說明可能損失，並介紹替代方案：

| 客戶需求 | 可考慮的替代方案 |
|---|---|
| 暫時繳不出保費 | 變更繳別、自動墊繳、減額繳清、展期定期 |
| 需要一筆現金 | 保單借款 |
| 覺得保額太高 | 保額減少（部分解約） |

（各方案說明見 GLO-001，作業流程見 OPS-SOP-002）

## 單元四：契約效力的時間軸

```
投保 → 核保承保 → 保單送達 →（10 日契約撤銷期）→ 有效 → 欠繳保費 → 寬限期 → 停效 → 復效／2 年後終止
```

重點提醒：
- 撤銷期內撤銷：**全額無息退費**，契約自始無效
- 撤銷期後終止：只能領**解約金**
- 寬限期內出險：仍理賠
- 停效期間出險：**不理賠**

## 單元五：課後練習題

1. 客戶在收到保單第 7 天後悔了，可以怎麼做？可以拿回多少錢？
2. 客戶的月繳保單上個月忘了繳費，昨天住院，保險公司要理賠嗎？
3. 投資型保險的投資風險由誰承擔？
4. 實支實付型與日額型醫療險差在哪裡？

參考答案：(1) 行使契約撤銷權，無息退還全部已繳保費；(2) 若仍在寬限期內，契約有效，應理賠但扣除欠繳保費；(3) 要保人；(4) 實支實付依實際醫療費用收據核實給付，日額型依住院天數乘以日額給付。
