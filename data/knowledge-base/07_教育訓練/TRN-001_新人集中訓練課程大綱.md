# 新人集中訓練（3 日）課程大綱

## 一、基本資訊

- 對象：當月到職之所有內勤新進員工
- 時間：到職第 2–4 個工作天，每日 09:00–17:30
- 地點：23F 大訓練教室
- 請攜帶公司筆電（課程中有系統實機操作）
- 結訓測驗：第 3 天下午，線上測驗 **70 分**及格；不及格者於 2 週內參加補考

## 二、課程表

### 第 1 天：認識曦光人壽

| 時間 | 課程 | 講師單位 |
|---|---|---|
| 09:00–09:30 | 總經理致詞與公司願景、CARE 核心價值 | 總經理室 |
| 09:30–10:30 | 公司沿革、組織與各部門職掌 | 人力資源處 |
| 10:45–12:00 | 員工手冊重點：出勤、請假、福利、行為規範 | 人力資源處 |
| 13:00–14:30 | 保險基礎概論（一）：保險原理與契約關係人 | 訓練發展組（教材 TRN-002） |
| 14:45–16:00 | 保險基礎概論（二）：商品類型與保單價值 | 訓練發展組 |
| 16:15–17:30 | 新人座談：與前一年度新人交流 | 人力資源處 |

| 時間 | 課程 | 講師單位 |
|---|---|---|
| 09:00–10:30 | 一張保單的旅程：從要保書到保單製發（新契約與核保） | 核保部 |

### 第 3 天：法遵、資安與工具

| 時間 | 課程 | 講師單位 |

## 三、出席規定

- 新人集中訓練列為**必修**，缺課者須於下一梯次（次月）補訓缺課時段
- 因病或緊急事故缺課，依請假規定辦理（HR-002），並通知訓練發展組（分機 2150）
- 業務單位新人另有 5 日「業務員登錄前訓練」，由通路業務處另行通知
