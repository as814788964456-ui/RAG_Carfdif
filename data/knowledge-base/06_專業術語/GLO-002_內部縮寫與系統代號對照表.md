## 三、常見縮寫

| 縮寫 | 全稱 | 意思 |
|---|---|---|
| SSO | Single Sign-On | 單一登入，一組 AD 帳密登入多個系統 |
| AD 帳號 | Active Directory | 員工的公司電腦帳號 |
| SSPR | Self-Service Password Reset | 密碼自助重設 |
| MFA | Multi-Factor Authentication | 多因子驗證 |
| SLA | Service Level Agreement | 服務時效承諾（例如 IT 工單 P1 4 小時解決） |
| INC／REQ | Incident／Request | iService 事件工單／服務申請工單編號開頭 |
| P1–P4 | Priority 1–4 | IT 工單優先等級 |
| KYC | Know Your Customer | 認識客戶 |
| EDD | Enhanced Due Diligence | 加強客戶審查 |
| PEP | Politically Exposed Person | 重要政治性職務人士 |
| AML/CFT | Anti-Money Laundering / Countering the Financing of Terrorism | 防制洗錢與打擊資恐 |
| STR | Suspicious Transaction Report | 可疑交易申報 |
| CTR | Currency Transaction Report | 大額通貨交易申報 |
| TCF | Treating Customers Fairly | 公平待客原則 |
| APL | Automatic Premium Loan | 自動墊繳 |
| VIP 件 | — | 內部用語，指高保額案件（累計身故保額 3,000 萬元以上），核保由核保部經理親自覆核 |
| 照會件 | — | 核保或理賠需要客戶補件的案件 |
| 撤件 | — | 要保申請未完成而撤回（照會逾期、客戶不同意加費等） |
| 補件 | — | 文件不齊，要求業務員或客戶補送 |
| 週年日 | — | 保單生效日每年的對應日 |
| R01、R05… | — | LIFE-Core 角色代碼（SYS-001） |
| Buddy | — | 新人夥伴，陪伴新人前 3 個月的資深同仁（HR-005） |
| CARE | Customer First, Accountability, Respect, Excellence | 公司核心價值（GEN-001） |
