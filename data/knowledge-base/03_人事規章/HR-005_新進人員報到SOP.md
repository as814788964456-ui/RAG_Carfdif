# 新進人員報到作業 SOP

## 一、目的

讓新進員工於到職第一週順利完成行政手續、取得工作所需帳號與設備，並在 30 天內完成必修訓練。

## 二、到職前（人資與用人單位）

| 時間 | 工作 | 負責 |
|---|---|---|
| 到職前 7 個工作天 | 寄送「報到通知信」（含應備文件清單、報到時間地點） | 人資招募任用組 |
| 到職前 3 個工作天 | 通知資訊處準備帳號與筆電；通知總務處準備座位與識別證 | 人資招募任用組 |
| 到職前 3 個工作天 | 指定一位 **Buddy（新人夥伴）**，為同部門資深同仁，陪伴新人前 3 個月 | 用人單位主管 |
| 到職前 1 個工作天 | 由主管於 eFlow 提出新人所需系統權限申請（如 LIFE-Core，IT-05） | 用人單位主管 |

## 三、新人應備文件（報到當天繳交）

1. 身分證正反面影本
2. 最高學歷畢業證書影本
3. 前一份工作的離職證明（服務證明）正本（無工作經驗者免附）
4. **3 個月內**之公立或勞工體檢指定醫院一般體格檢查報告
5. 薪轉帳戶存摺封面影本（本公司薪轉銀行為「曦光合作銀行」，非該行帳戶者請於到職 1 週內開戶，人資會提供開戶證明）
6. 2 吋證件照 2 張（亦可上傳電子檔）
7. 擔任業務、核保或保全等需登錄職務者：保險業務員資格測驗合格證明（如已取得）

## 四、報到當天流程（Day 1）

| 時間 | 地點 | 內容 |
|---|---|---|
| 09:00–10:30 | 23F 人資處 | 繳交文件、簽署勞動契約、保密協定、個資同意書；領取識別證與「帳號開通單」 |
| 10:30–11:00 | 18F 資訊處服務櫃台 | 憑帳號開通單領取筆電、首次登入、設定 MFA、跟印綁定（見 IT-FAQ-007） |
| 11:00–12:00 | 所屬部門 | 主管介紹部門同仁、Buddy 帶領熟悉座位與環境 |
| 13:30–17:00 | 線上 | 開始 e-Learning 必修課程（見第六節） |

## 五、第一週

- 第 2–4 天：參加「新人集中訓練」3 天（課程見 TRN-001），地點 23F 大訓練教室
- 第 5 天：與直屬主管進行第一次一對一面談，確認試用期目標

## 六、30 天內須完成的 e-Learning 必修課程

| 課程 | 時數 | 說明 |
|---|---|---|
| 個人資料保護 | 1.5 小時 | **完成後才會開通 LIFE-Core 權限** |
| 防制洗錢與打擊資恐 | 2 小時 | 主管機關要求，須於到職 30 天內完成並通過測驗（80 分及格） |
| 資訊安全意識 | 1 小時 | |
| 公平待客原則 | 1 小時 | |
| 職場性騷擾防治 | 1 小時 | |

未於期限內完成者，人資將通知直屬主管，並列入試用期考核。

## 七、試用期

試用期 3 個月，期滿前 2 週由主管進行考核（HR-001 第二章）。人資於到職第 30 天與第 80 天各安排一次新人關懷訪談。

## 八、常見問題

- **報到當天找不到人？** 請至 1F 櫃台告知為新進員工，櫃台會聯絡人資（分機 2100）帶您上樓
- **體檢報告來不及？** 可先報到，最晚於到職後 **2 週內**補交
- **筆電還沒準備好？** 先向 18F 服務櫃台借用備品筆電（IT-FAQ-007 Q3）
