# 國內外出差管理辦法

## 第一條 出差申請

1. 出差前於 eFlow 提出 **FIN-02「出差申請單」**，載明地點、期間、事由、預估費用
2. 簽核：國內出差 → 直屬主管；國外出差 → 直屬主管 → 處級主管 → 總經理
3. 國外出差應於出發前 **10 個工作天**提出
4. 出差返回後 **30 天內**於 eExpense 辦理差旅費報銷（SYS-004、ADM-001）

## 第二條 國內出差交通

| 交通工具 | 規定 |
|---|---|
| 高鐵、台鐵 | 高鐵**標準車廂**、台鐵自強號以下 |
| 國內航線 | 前往離島或花東地區，經主管核准者可搭乘經濟艙 |
| 計程車 | 原則不予報銷；以下情形例外：22:00 後返程、攜帶大量文件或設備、當地無大眾運輸，需於報銷時註明事由 |
| 自用車 | 每公里補助新台幣 3 元，另核實報銷過路費與停車費；需事前於出差申請單註明 |

## 第三條 國內住宿與膳雜費

| 項目 | 上限（新台幣） |
|---|---|
| 住宿費（台北市、新北市以外） | 每晚 **2,800 元**，核實報銷（需統編發票或收據） |
| 住宿費（台北市、新北市） | 原則不核給，特殊情形經處級主管核准者每晚 3,500 元 |
| 膳雜費（當日往返） | 每日 **500 元**，定額支給免附單據 |
| 膳雜費（需過夜） | 每日 **800 元**，定額支給免附單據 |

出差地點由公司或主辦單位提供餐食者，膳雜費減半支給。

## 第四條 國外出差

| 項目 | 規定 |
|---|---|
| 機票 | 經濟艙；單程飛行 8 小時以上且職級為協理以上者可搭商務艙 |
| 住宿與膳雜費（日支費） | 依目的地分級：亞洲地區每日 USD 200、歐美地區每日 USD 280（含住宿與膳雜費），超過部分自行負擔 |
| 匯率 | 以出發日台灣銀行即期賣出匯率換算 |
| 差旅平安保險 | 由公司統一投保，員工無須自行投保（保額 新台幣 500 萬元） |

## 第五條 不予報銷項目

- 個人消費（洗衣、迷你吧、付費電視、個人娛樂）
- 未經核准之升等艙位或住宿
- 延長行程之私人旅遊期間費用
- 交通違規罰單

## 第六條 出差期間之保險與安全

出差期間如發生意外，請立即通知直屬主管及人力資源處（分機 2100）。國外出差遇緊急狀況，可撥打團體差旅保險 24 小時海外急難救助專線（號碼印於出差前寄送之保險卡）。
